# Health-Condition-ML-Classification
Machine learning project for classifying health conditions using data preprocessing, model training, and evaluation with Weka and RapidMiner

This project applies machine learning techniques to classify health-related conditions based on structured dataset features.

## Objectives
- Analyze health-related dataset
- Train machine learning models
- Evaluate model performance

## Technologies
- Machine Learning
- Weka
- RapidMiner
- Data preprocessing

## Workflow
1. Data preprocessing
2. Feature selection
3. Model training
4. Performance evaluation

## Results
The models were evaluated using classification accuracy and confusion matrix analysis.
